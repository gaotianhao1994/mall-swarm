## 架构调整说明

> **2026-06-11 新增第三台服务器，架构从 2 台调整为 3 台**

### 为什么调整？

原方案腾讯云 4核4G 一台机器同时跑 MySQL + Redis + Nacos + Gateway + Admin + Auth 共 6 个容器，
导致 **CPU 负载 90%**，内存接近满载。将基础数据层和核心业务拆到新服务器后：

| 对比项 | 原方案（2台） | 新方案（3台） |
|--------|-------------|-------------|
| 网关服务器负载 | ~90% CPU, 内存紧张 | ~30% CPU, 宽裕 |
| 数据服务器负载 | — | ~40% CPU, 宽裕 |
| 扩展服务器负载 | 不变 | 不变 |
| 单点故障影响 | 全部服务不可用 | 仅影响部分服务 |
