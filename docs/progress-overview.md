## 阶段准入条件（Check Before You Start）

### 开始阶段1之前，必须完成：

- [ ] 腾讯云：Docker ✅ / Docker Compose ✅ / Git ✅
- [ ] 腾讯云：安全组端口已开放（22, 80, 3306, 6379, 8848, 8201, 8080, 8401）
- [ ] 阿里云：Docker ✅ / Docker Compose ✅ / Git ✅
- [ ] 阿里云：安全组端口已开放（22, 9200, 27017, 5672, 15672, 5601）
- [ ] 两台服务器互相能 ping 通（hosts 已配置或内网互通）

### 开始阶段2之前，必须完成：

- [ ] 阶段1 所有服务运行正常（腾讯云）
- [ ] GitHub Actions CI/CD 能正常构建推送镜像
- [ ] 阿里云能从 ACR 拉取镜像

### 开始阶段3之前，必须完成：

- [ ] 阶段2 的 ES 和 mall-search 运行正常
- [ ] 主服务器内存有余量

### 开始阶段4之前，必须完成：

- [ ] 阶段1~3 全部服务稳定运行
- [ ] 两台服务器内存经过调优
