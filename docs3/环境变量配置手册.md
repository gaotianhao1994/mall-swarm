# mall-swarm 环境变量配置手册

> 最后更新: 2026-06-19

本文档列出 docker-compose 中使用的所有环境变量，供部署和运维参考。

---

## 一、环境变量总览

所有变量定义在 `docker/.env` 文件中。docker-compose 文件通过 `${变量名:-默认值}` 引用。

**⚠️ 注意：`.env` 文件包含密码，已在 `.gitignore` 中排除，不会提交到 Git。**

---

## 三、变量在各 docker-compose 文件中的使用

### tengxun-server.yml 使用的变量

```
ACR_REGISTRY, ACR_NAMESPACE     → 构建镜像地址
NACOS_AUTH_TOKEN                → Nacos 认证
NACOS_PORT                      → Nacos 端口
ES_PORT, ES_TCP_PORT            → Elasticsearch 端口
REDIS_PASSWORD                  → Gateway Redis 连接
MYSQL_ROOT_PASSWORD             → Search MySQL 连接
ES_ADDR                         → Search ES 连接
MYSQL_ADDR                      → Search MySQL 连接
REDIS_ADDR                      → Gateway Redis 连接
GATEWAY_PORT                    → Gateway 端口
SEARCH_PORT                     → Search 端口
DATA_DIR, LOG_DIR               → 数据和日志目录
```

### tengxun-server9.yml 使用的变量

```
ACR_REGISTRY, ACR_NAMESPACE     → 构建镜像地址
MYSQL_ROOT_PASSWORD             → MySQL root 密码
MYSQL_PORT                      → MySQL 端口
REDIS_PASSWORD                  → Redis 密码 + Auth Redis 连接
REDIS_PORT                      → Redis 端口
NACOS_ADDR                      → Admin/Auth Nacos 地址
ADMIN_PORT, AUTH_PORT           → 服务端口
DATA_DIR, LOG_DIR               → 数据和日志目录
```

### aliyun-server.yml 使用的变量

```
ACR_REGISTRY, ACR_NAMESPACE     → 构建镜像地址
RABBITMQ_USER, RABBITMQ_PASSWORD → RabbitMQ 凭证
RABBITMQ_PORT, RABBITMQ_MGMT_PORT → RabbitMQ 端口
MONGO_PORT                      → MongoDB 端口
NACOS_ADDR                      → Portal/Monitor Nacos 地址
MYSQL_ROOT_PASSWORD             → Portal MySQL 连接
MYSQL_ADDR                      → Portal MySQL 地址
REDIS_PASSWORD                  → Portal Redis 连接
REDIS_ADDR                      → Portal Redis 地址
MONGO_ADDR                      → Portal MongoDB 地址
RABBITMQ_ADDR                   → Portal RabbitMQ 地址
PORTAL_PORT, MONITOR_PORT       → 服务端口
DATA_DIR, LOG_DIR               → 数据和日志目录
```
