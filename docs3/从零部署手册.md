## 三、第一步：服务器基础准备

在**三台服务器上**分别执行以下操作。

### 3.1 安装 Docker

```bash
# 安装 Docker（Ubuntu/Debian）
curl -fsSL https://get.docker.com | sh
systemctl enable docker && systemctl start docker

# 验证
docker --version
```

### 3.2 安装 Docker Compose

```bash
# Docker Compose V2（随 Docker 一起安装，验证即可）
docker compose version
```

### 3.3 安装基础工具

```bash
# 安装 git、curl、python3（Nacos 配置导入脚本需要）
apt update && apt install -y git curl python3
```

### 3.4 创建项目目录

```bash
# 在三台服务器上都执行
mkdir -p /root/projects/mall-swarm
```

## 四、第二步：部署 tengxun-server9（数据层）

**先部署数据层**，因为其他服务都依赖 MySQL 和 Redis。

### 4.1 拉取代码

```bash
ssh root@106.53.132.192

cd /root/projects
git clone https://github.com/gaotianhao1994/mall-swarm.git
cd mall-swarm
```

### 4.2 创建 .env 文件

```bash
cd docker

cat > .env << 'EOF'
ACR_REGISTRY=crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com
ACR_NAMESPACE=mall-swarm-202606
NACOS_ADDR=106.53.106.41:8848
MYSQL_ROOT_PASSWORD=Mall@2026_root
REDIS_PASSWORD=Mall@2026_redis
DATA_DIR=/root/projects/mall-swarm/data
LOG_DIR=/root/projects/mall-swarm/logs
EOF
```

### 4.3 创建数据和日志目录

```bash
mkdir -p /root/projects/mall-swarm/data/{mysql,redis}
mkdir -p /root/projects/mall-swarm/logs/{admin,auth}
```

### 4.4 启动服务

```bash
docker compose -f docker-compose-tengxun-server9.yml up -d
```

### 4.5 验证

```bash
# 查看容器状态（等待所有容器 healthy）
docker compose -f docker-compose-tengxun-server9.yml ps

# 测试 MySQL 连接
docker exec mall-mysql mysql -uroot -pMall@2026_root -e "SHOW DATABASES;"

# 测试 Redis 连接
docker exec mall-redis redis-cli -a Mall@2026_redis ping
```

**预期输出：** MySQL 显示数据库列表包含 `mall`，Redis 返回 `PONG`。

## 五、第三步：部署 tengxun-server（网关层）

### 5.1 拉取代码

```bash
ssh root@106.53.106.41

cd /root/projects
git clone https://github.com/gaotianhao1994/mall-swarm.git
cd mall-swarm
```

### 5.2 创建 .env 文件

```bash
cd docker

cat > .env << 'EOF'
ACR_REGISTRY=crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com
ACR_NAMESPACE=mall-swarm-202606
NACOS_AUTH_TOKEN=SecretKey012345678901234567890123456789012345678901234567890123456789
REDIS_PASSWORD=Mall@2026_redis
MYSQL_ROOT_PASSWORD=Mall@2026_root
ES_PORT=9200
ES_TCP_PORT=9300
GATEWAY_PORT=8201
SEARCH_PORT=8081
DATA_DIR=/root/projects/mall-swarm/data
LOG_DIR=/root/projects/mall-swarm/logs
EOF
```

### 5.3 创建数据和日志目录

```bash
mkdir -p /root/projects/mall-swarm/data/{es/data,es/plugins,nacos}
mkdir -p /root/projects/mall-swarm/logs/{gateway,search}
```

### 5.4 启动服务

```bash
docker compose -f docker-compose-tengxun-server.yml up -d
```

### 5.5 导入 Nacos 配置

**等待 Nacos 启动完成**（约 1-2 分钟），然后导入配置：

```bash
# 方法一：使用导入脚本（推荐）
cd docker/nacos-config
chmod +x import-config.sh
./import-config.sh 127.0.0.1:8848 nacos nacos

# 方法二：手动导入（如果脚本不工作）
for f in *-prod.yaml; do
  curl -X POST "http://127.0.0.1:8848/nacos/v1/cs/configs" \
    -d "dataId=$f&group=DEFAULT_GROUP&type=yaml" \
    --data-urlencode "content@=$f"
done
```

### 5.6 安装 IK 分词插件

```bash
docker exec mall-elasticsearch bin/elasticsearch-plugin install \
  -b https://get.infini.cloud/elasticsearch/analysis-ik/7.17.3

# 安装后需要重启 ES
docker restart mall-elasticsearch
```

### 5.7 验证

```bash
# 查看容器状态
docker compose -f docker-compose-tengxun-server.yml ps

# 测试 Nacos
curl -s http://127.0.0.1:8848/nacos/v1/console/health/liveness

# 测试 Elasticsearch
curl -s http://127.0.0.1:9200/_cluster/health | python3 -m json.tool

# 测试 Gateway
curl -s http://127.0.0.1:8201/actuator/health

# 测试前端页面
curl -sI http://127.0.0.1/
curl -sI http://127.0.0.1:8085/
```

**预期输出：** Nacos 返回 OK，ES 返回集群健康状态，Gateway 返回 UP，前端返回 200。

## 七、第五步：验证全链路

### 7.1 测试 Gateway → mall-admin

```bash
# 在 tengxun-server 上执行
curl -s http://127.0.0.1:8201/mall-admin/admin/login \
  -X POST -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"macro123"}'
```

**预期：** 返回 `{"code":200,"message":"登录成功",...}`

### 7.2 测试 Gateway → mall-portal

```bash
# 在 tengxun-server 上执行
curl -s http://127.0.0.1:8201/mall-portal/home/content
```

**预期：** 返回 `{"code":200,"data":{"advertiseList":[...],...}}`

### 7.3 测试前端页面

在浏览器中访问：

| 地址 | 预期结果 |
|------|---------|
| http://106.53.106.41 | 后台管理登录页 |
| http://106.53.106.41:8085 | 商城 H5 首页 |

**后台管理登录：** 用户名 `admin`，密码 `macro123`

### 7.4 测试通过 Nginx 代理的 API

```bash
# 通过前端 Nginx 代理访问（不是直接访问 Gateway）
curl -s http://106.53.106.41/mall-admin/admin/login \
  -X POST -H 'Content-Type: application/json' \
  -d '{"username":"admin","password":"macro123"}'

curl -s http://106.53.106.41:8085/mall-portal/home/content
```

**预期：** 同样返回 200，说明前端 Nginx → Gateway → 后端 全链路通了。

## 九、常见问题排查

### Q1: 容器启动后立即退出

```bash
# 查看容器日志
docker logs <容器名> --tail 50

# 常见原因：
# - 端口被占用：netstat -tlnp | grep <端口>
# - 依赖服务未就绪：等待后重试
# - 镜像拉取失败：检查网络和 ACR 凭证
```

### Q2: Gateway 返回 502 Bad Gateway

```bash
# 检查后端服务是否注册到 Nacos
curl -s 'http://106.53.106.41:8848/nacos/v1/ns/instance/list?serviceName=mall-admin'

# 如果 hosts 为空，说明服务没有注册成功
# 检查 SPRING_CLOUD_NACOS_DISCOVERY_IP 是否正确设置
```

### Q3: 跨服务器连接超时

```bash
# 测试服务器间网络连通性
ping 106.53.132.192  # 从 tengxun-server 测试
ping 106.53.106.41   # 从 tengxun-server9 测试
curl -s http://106.53.132.192:3306  # 测试 MySQL 端口

# 如果 ping 通但端口不通，检查安全组/防火墙
```

### Q4: mall-app-web 首页无数据

```bash
# 检查 mall-portal 是否正常
curl -s http://8.134.65.121:8085/actuator/health

# 检查 MongoDB 数据库是否有数据
docker exec mall-mongo mongo mall-port --eval "db.getCollectionNames()"

# 如果集合为空，需要导入首页数据（参考 mall.sql）
```

### Q5: 前端页面白屏

```bash
# 检查 Nginx 是否正常
curl -sI http://106.53.106.41/
curl -sI http://106.53.106.41:8085/

# 检查容器日志
docker logs mall-admin-nginx --tail 20
docker logs mall-app-nginx --tail 20
```
