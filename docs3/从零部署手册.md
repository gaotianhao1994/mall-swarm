## 一、项目概览（必读）

### 1.1 三个 Git 仓库

本项目由 **3 个独立的 GitHub 仓库** 组成，缺一不可：

| 仓库 | 地址 | 内容 | 部署位置 |
|------|------|------|---------|
| **mall-swarm** | `github.com/gaotianhao1994/mall-swarm` | Java 后端微服务 + Docker 编排 + Nacos 配置 | 三台服务器都需要 |
| **mall-admin-web** | `github.com/gaotianhao1994/mall-admin-web` | 后台管理前端（Vue3 + Vite） | 镜像构建后推送到 ACR |
| **mall-app-web** | `github.com/gaotianhao1994/mall-app-web` | 商城 H5 前端（uni-app） | 镜像构建后推送到 ACR |

### 1.2 镜像来源

所有 Docker 镜像都存在**阿里云 ACR 镜像仓库**中，通过 `docker compose pull` 拉取：

| 镜像 Tag | 来源仓库 | 构建方式 |
|----------|---------|---------|
| `mall-gateway-latest` | mall-swarm | GitHub Actions 自动构建 |
| `mall-admin-latest` | mall-swarm | GitHub Actions 自动构建 |
| `mall-auth-latest` | mall-swarm | GitHub Actions 自动构建 |
| `mall-search-latest` | mall-swarm | GitHub Actions 自动构建 |
| `mall-portal-latest` | mall-swarm | GitHub Actions 自动构建 |
| `mall-monitor-latest` | mall-swarm | GitHub Actions 自动构建 |
| `mall-admin-web-latest` | mall-admin-web | GitHub Actions 自动构建 |
| `mall-app-web-latest` | mall-app-web | GitHub Actions 自动构建 |

**正常部署不需要自己构建镜像**，直接从 ACR 拉取即可。只有修改了代码后才需要重新构建（见[附录 A](#附录-a-重新构建前端镜像)）。

## 五、第二步：部署 tengxun-server9（数据层）

**先部署数据层**，因为其他服务都依赖 MySQL 和 Redis。

### 5.1 拉取代码

```bash
ssh root@106.53.132.192

cd /root/projects
git clone https://github.com/gaotianhao1994/mall-swarm.git
cd mall-swarm/docker
```

### 5.2 创建 .env 文件

```bash
cat > .env << 'EOF'
ACR_REGISTRY=crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com
ACR_NAMESPACE=mall-swarm-202606
NACOS_ADDR=106.53.106.41:8848
MYSQL_ROOT_PASSWORD=Mall@2026_root
REDIS_PASSWORD=Mall@2026_redis
DATA_DIR=/root/projects/mall-swarm/data
LOG_DIR=/root/projects/mall-swarm/logs
EOF
```

### 5.3 创建数据和日志目录

```bash
mkdir -p /root/projects/mall-swarm/data/{mysql,redis}
mkdir -p /root/projects/mall-swarm/logs/{admin,auth}
```

### 5.4 启动服务

```bash
docker compose -f docker-compose-tengxun-server9.yml up -d
```

### 5.5 验证

```bash
# 等待所有容器 healthy（约 1-2 分钟）
docker compose -f docker-compose-tengxun-server9.yml ps

# 测试 MySQL
docker exec mall-mysql mysql -uroot -pMall@2026_root -e "SHOW DATABASES;"

# 测试 Redis
docker exec mall-redis redis-cli -a Mall@2026_redis ping
```

**预期：** MySQL 显示 `mall` 数据库，Redis 返回 `PONG`。

## 六、第三步：部署 tengxun-server（网关层）

### 6.1 拉取代码

```bash
ssh root@106.53.106.41

cd /root/projects
git clone https://github.com/gaotianhao1994/mall-swarm.git
cd mall-swarm/docker
```

### 6.2 创建 .env 文件

```bash
cat > .env << 'EOF'
ACR_REGISTRY=crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com
ACR_NAMESPACE=mall-swarm-202606
NACOS_AUTH_TOKEN=SecretKey012345678901234567890123456789012345678901234567890123456789
REDIS_PASSWORD=Mall@2026_redis
MYSQL_ROOT_PASSWORD=Mall@2026_root
ES_PORT=9200
ES_TCP_PORT=9300
GATEWAY_PORT=8201
SEARCH_PORT=8081
DATA_DIR=/root/projects/mall-swarm/data
LOG_DIR=/root/projects/mall-swarm/logs
EOF
```

### 6.3 创建数据和日志目录

```bash
mkdir -p /root/projects/mall-swarm/data/{es/data,es/plugins,nacos}
mkdir -p /root/projects/mall-swarm/logs/{gateway,search}
```

### 6.4 启动服务

```bash
docker compose -f docker-compose-tengxun-server.yml up -d
```

**⚠️ 首次启动会拉取所有镜像，需要 10-30 分钟（取决于网速）。**

### 6.5 导入 Nacos 配置

等待 Nacos 启动完成（约 1-2 分钟），然后导入配置：

```bash
cd docker/nacos-config
chmod +x import-config.sh
./import-config.sh 127.0.0.1:8848 nacos nacos
```

### 6.6 安装 IK 分词插件

```bash
docker exec mall-elasticsearch bin/elasticsearch-plugin install \
  -b https://get.infini.cloud/elasticsearch/analysis-ik/7.17.3

docker restart mall-elasticsearch
```

### 6.7 验证

```bash
docker compose -f docker-compose-tengxun-server.yml ps

curl -s http://127.0.0.1:8848/nacos/v1/console/health/liveness
curl -s http://127.0.0.1:9200/_cluster/health
curl -s http://127.0.0.1:8201/actuator/health
curl -sI http://127.0.0.1/
curl -sI http://127.0.0.1:8085/
```

## 九、常见问题排查

### Q1: 镜像拉取失败（image not found）

```bash
# 检查 ACR 镜像是否存在
docker pull crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com/mall-swarm-202606/mall-swarm-202606:mall-gateway-latest

# 如果报错，可能是 GitHub Actions 没跑过或失败了
# 需要手动构建镜像（见附录 A）
```

### Q2: 容器启动后立即退出

```bash
docker logs <容器名> --tail 50
# 常见原因：端口被占用 / 依赖服务未就绪 / 镜像拉取失败
```

### Q3: Gateway 返回 502 Bad Gateway

```bash
# 检查服务是否注册到 Nacos
curl -s 'http://106.53.106.41:8848/nacos/v1/ns/instance/list?serviceName=mall-admin'
# hosts 为空说明服务没注册成功，检查 SPRING_CLOUD_NACOS_DISCOVERY_IP
```

### Q4: 跨服务器连接超时

```bash
# 测试网络连通性
ping 106.53.132.192
# ping 通但端口不通 → 检查安全组/防火墙
```

### Q5: mall-app-web 首页无数据

```bash
# 检查 mall-portal
curl -s http://8.134.65.121:8085/actuator/health
# 检查 MongoDB
docker exec mall-mongo mongo mall-port --eval "db.getCollectionNames()"
```
