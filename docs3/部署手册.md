## 二、镜像和容器的关系

### 2.1 GitHub Actions 构建了 6 个镜像

GitHub Actions 自动构建并推送到阿里云 ACR（镜像仓库）：

| 镜像名 | 来源模块 | 用途 |
|--------|---------|------|
| `mall-gateway-latest` | mall-gateway/ | API 网关 |
| `mall-admin-latest` | mall-admin/ | 后台管理 |
| `mall-auth-latest` | mall-auth/ | 认证授权 |
| `mall-search-latest` | mall-search/ | 商品搜索 |
| `mall-portal-latest` | mall-portal/ | 前台商城 |
| `mall-monitor-latest` | mall-monitor/ | 服务监控 |

### 2.2 镜像在哪？

镜像存在阿里云 ACR 云端，不在本地电脑，也不在服务器上。

你可以在阿里云控制台 → 容器镜像服务 → `mall-swarm-202606` 仓库看到它们。

### 2.3 怎么用？

```
服务器执行 docker compose up
        │
        ▼
docker 从 ACR 拉取镜像（如 mall-admin-latest）
        │
        ▼
镜像变成容器运行起来
```

## 五、分阶段部署计划

### 阶段1: 基础骨架（目标：mall-admin 后台可访问）

**在 tengxun-server9 上执行：**
1. clone 项目到 `/root/projects/mall-swarm`
2. 创建 `.env` 文件
3. 启动 `docker-compose-tengxun-server9.yml`（mall-mysql + mall-redis + mall-admin + mall-auth）

**在 tengxun-server 上执行：**
4. 启动 `docker-compose-tengxun-server.yml`（mall-nacos + mall-gateway + mall-nginx）
5. 导入 Nacos 配置

**验证：**
6. 访问 `http://106.53.106.41` 看到 mall-nginx 页面
7. 访问 Nacos 控制台 `http://106.53.106.41:8848/nacos`
8. 通过 mall-gateway 调用 mall-admin API

### 阶段2: 商品搜索

**在 tengxun-server 上执行：**
9. 确认 mall-elasticsearch 启动正常
10. 确认 mall-search 注册到 Nacos

### 阶段3: 前台商城

**在 aliyun-server 上执行：**
11. 启动 `docker-compose-aliyun-server.yml`（mall-mongo + mall-rabbitmq + mall-portal + mall-monitor）

### 阶段4: 完整验证

12. 通过 mall-gateway 访问所有服务
13. 前端页面部署（后续）

## 九、前端部署

### 9.1 前端项目概览

| 前端 | 本地路径 | 用途 | 构建命令 |
|------|---------|------|---------|
| mall-admin-web | `E:\projects\202606\mall-admin-web` | 后台管理系统 | `npm run build` |
| mall-app-web | `E:\projects\202606\mall-app-web` | 商城H5前端(uni-app) | `npm run build:h5` |

### 9.2 前端 Docker 镜像

两个前端项目各自包含 `Dockerfile` 和 `nginx.conf`，采用多阶段构建：
- **Stage 1**: Node.js 构建前端静态文件
- **Stage 2**: Nginx 服务静态文件 + 反向代理 API 到 Gateway

镜像通过 GitHub Actions 自动构建并推送到 ACR：

| 镜像名 | 构建产物路径 | Nginx 端口 |
|--------|------------|-----------|
| `mall-admin-web-latest` | `/app/dist` | 80 |
| `mall-app-web-latest` | `/app/dist/build/h5` | 80 |

### 9.3 前端部署到 tengxun-server (106.53.106.41)

前端容器运行在 tengxun-server 上，与 mall-gateway 在同一 Docker 网络 `docker_default`。

**部署命令（在 tengxun-server 上执行）：**

```bash
# 拉取前端镜像
docker pull crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com/mall-swarm-202606/mall-swarm-202606:mall-admin-web-latest
docker pull crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com/mall-swarm-202606/mall-swarm-202606:mall-app-web-latest

# 启动 mall-admin-nginx（后台管理前端）
docker run -d \
  --name mall-admin-nginx \
  --network docker_default \
  -p 80:80 \
  crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com/mall-swarm-202606/mall-swarm-202606:mall-admin-web-latest

# 启动 mall-app-nginx（商城H5前端）
docker run -d \
  --name mall-app-nginx \
  --network docker_default \
  -p 8085:80 \
  crpi-9lhedueyyvqzcyrk.cn-guangzhou.personal.cr.aliyuncs.com/mall-swarm-202606/mall-swarm-202606:mall-app-web-latest
```

### 9.4 前端 Nginx 配置说明

两个前端的 `nginx.conf` 都配置了：

1. **API 反向代理** → 通过 `mall-gateway:8201` 转发到后端微服务
2. **Vue Router history 模式** → `try_files $uri $uri/ /index.html`
3. **静态资源缓存** → JS/CSS/图片等 7 天缓存

**mall-admin-web nginx 代理路径：**
- `/mall-admin/` → Gateway → mall-admin 后端
- `/mall-auth/` → Gateway → mall-auth 认证服务
- `/admin/` → Gateway → mall-admin（兼容旧路径）

**mall-app-web nginx 代理路径：**
- `/mall-admin/` → Gateway → mall-admin 后端
- `/mall-auth/` → Gateway → mall-auth 认证服务
- `/mall-portal/` → Gateway → mall-portal 前台商城
- `/mall-search/` → Gateway → mall-search 搜索服务
