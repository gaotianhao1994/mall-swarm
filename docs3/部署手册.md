## 二、镜像和容器的关系

### 2.1 GitHub Actions 构建了 6 个镜像

GitHub Actions 自动构建并推送到阿里云 ACR（镜像仓库）：

| 镜像名 | 来源模块 | 用途 |
|--------|---------|------|
| `mall-gateway-latest` | mall-gateway/ | API 网关 |
| `mall-admin-latest` | mall-admin/ | 后台管理 |
| `mall-auth-latest` | mall-auth/ | 认证授权 |
| `mall-search-latest` | mall-search/ | 商品搜索 |
| `mall-portal-latest` | mall-portal/ | 前台商城 |
| `mall-monitor-latest` | mall-monitor/ | 服务监控 |

### 2.2 镜像在哪？

镜像存在阿里云 ACR 云端，不在本地电脑，也不在服务器上。

你可以在阿里云控制台 → 容器镜像服务 → `mall-swarm-202606` 仓库看到它们。

### 2.3 怎么用？

```
服务器执行 docker compose up
        │
        ▼
docker 从 ACR 拉取镜像（如 mall-admin-latest）
        │
        ▼
镜像变成容器运行起来
```

## 五、分阶段部署计划

### 阶段1: 基础骨架（目标：mall-admin 后台可访问）

**在 tengxun-server9 上执行：**
1. clone 项目到 `/root/projects/mall-swarm`
2. 创建 `.env` 文件
3. 启动 `docker-compose-tengxun-server9.yml`（mall-mysql + mall-redis + mall-admin + mall-auth）

**在 tengxun-server 上执行：**
4. 启动 `docker-compose-tengxun-server.yml`（mall-nacos + mall-gateway + mall-nginx）
5. 导入 Nacos 配置

**验证：**
6. 访问 `http://106.53.106.41` 看到 mall-nginx 页面
7. 访问 Nacos 控制台 `http://106.53.106.41:8848/nacos`
8. 通过 mall-gateway 调用 mall-admin API

### 阶段2: 商品搜索

**在 tengxun-server 上执行：**
9. 确认 mall-elasticsearch 启动正常
10. 确认 mall-search 注册到 Nacos

### 阶段3: 前台商城

**在 aliyun-server 上执行：**
11. 启动 `docker-compose-aliyun-server.yml`（mall-mongo + mall-rabbitmq + mall-portal + mall-monitor）

### 阶段4: 完整验证

12. 通过 mall-gateway 访问所有服务
13. 前端页面部署（后续）
